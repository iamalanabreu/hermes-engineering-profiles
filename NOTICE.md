# Origin and attribution

This package contains original procedures, configuration, documentation and helpers
authored for the requested three-profile boilerplate. The existing Agent Folder
Architect supplied by the requester is retained and adapted; its original file hashes
are recorded in docs/source-audit/agent-folder-origin.json. Its scaffold renderer,
validator and original regression tests preserve their provenance.

Hermes Agent is an external project by Nous Research and contributors. This package
is not an official Nous Research release and does not modify the Hermes core.
Community repositories discussed during discovery were architectural references,
not an instruction to vendor their prompts or executable code. No AGPL profile pack
was copied into this distribution. Links do not relicense the linked projects.
